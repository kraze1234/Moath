# استوديو قصص الرعب — رسوم متحركة ثنائية الأبعاد من نص القصة

تكتب القصة بالعربي، فيقسّمها البرنامج إلى مشاهد، ويختار الخلفيات والشخصيات والحركات والكاميرا والمؤثرات،
ويحرّك كل شيء تلقائيًا، ثم تراجع وتعدّل وتصدّر فيديو MP4 عموديًا (1080×1920، 30 إطارًا في الثانية) جاهزًا لتيك توك وشورتس وريلز.

الأسلوب مسطّح تمامًا: أشكال هندسية وألوان صريحة، رجال بثياب وشمغ، بيوت طينية، مسجد صغير بمئذنة.

## التشغيل

المتطلبات: Node.js 20+، وffmpeg، وPython 3 (لتوليد المؤثرات مرة واحدة).
اختياري: `espeak-ng` لصوت راوٍ عربي مجاني (آلي)، مثل `sudo apt install espeak-ng` أو `brew install espeak-ng`.

```bash
cd horror-studio
npm install
npm run sfx        # يولّد المؤثرات الصوتية في public/sfx (موجودة مسبقًا في المستودع)
npm run dev        # الخادم على 3001 والواجهة على http://localhost:5173
```

افتح http://localhost:5173 ثم:
1. اكتب القصة أو اترك المثال، واضغط **أنشئ الرسوم المتحركة**.
2. شاهد المعاينة، وعدّل أي مشهد من **محرر المشهد** (الخلفية، الشخصيات وحركاتها ومواضعها، الكاميرا، الإضاءة، المدة، الحوار، المؤثرات).
3. الفيديو **صامت افتراضيًا** (الترجمة وحدها تحكي القصة). لإضافة صوت ألغِ «فيديو صامت»، ثم ولّد صوت الراوي أو ارفع تسجيلك لكل مشهد (المدة والترجمة تتبعان الصوت).
   - إذا ذكرت القصة فتح الباب، ينتهي الفيديو بخيارين: «افتح الباب» (بنفسجي غامق) و«لا تفتح الباب». تعدّلهما أو تلغيهما من الواجهة.
   - اسم البطل يظهر في بطاقة فوقه أول ما يطلع، ويمكن إضافة اسم لأي شخصية من المحرر.
4. اضغط **تصدير MP4** وانتظر شريط التقدم، ثم نزّل الفيديو.

مثال كامل من سطر الأوامر بلا واجهة: `npm run sample` (صامت؛ أو `npm run sample -- --voice` بصوت espeak-ng) ← `data/outputs/sample.mp4` (نسخة جاهزة منه في `samples/sample.mp4`).
لقطات ثابتة سريعة من كل مشهد للمراجعة: `npx tsx scripts/stills.ts`.

تشغيل نسخة الإنتاج على منفذ واحد: `npm run build && npm start` ثم افتح http://localhost:3001.

### متصفح التصدير
يستخدم Remotion متصفح Chrome بدون واجهة. يحمّله تلقائيًا أول مرة، أو حدّد مساره بنفسك:
`REMOTION_BROWSER=/path/to/chrome-headless-shell npm run dev`

## الخدمات الاختيارية (تحتاج مفاتيح)

| الميزة | المتغير | الحالة |
|---|---|---|
| المخرج بالذكاء الاصطناعي (Claude) يفهم القصص الحرة أفضل من القواعد | `ANTHROPIC_API_KEY` (واختياريًا `ANTHROPIC_MODEL`) | مكتوب لكنه **لم يُختبر** هنا لعدم توفر مفتاح |
| صوت راوٍ طبيعي (ElevenLabs، أصوات عربية متعددة) | `ELEVENLABS_API_KEY` + Voice ID في الواجهة | مكتوب لكنه **لم يُختبر** هنا لعدم توفر مفتاح |

بدون مفاتيح يعمل كل شيء آخر: المخرج المحلي، الرسوم، الحركة، الترجمة، المؤثرات، صوت espeak-ng، التصدير.
الواجهة تُظهر في الأعلى ما هو متاح فعلًا.

```bash
ANTHROPIC_API_KEY=... ELEVENLABS_API_KEY=... npm run dev
```

## كيف يعمل

```
القصة ──► المخرج (src/shared/director.ts محلي، أو server/llm.ts مع Claude)
          └─► مشاهد منظمة: خلفية، شخصيات {نوع، حركة، من، إلى، اتجاه، تعبير}، أشياء، كاميرا، إضاءة، مؤثرات، حوار
              └─► محرك Remotion (src/remotion) يرسمها SVG ويحرّكها
                  ├─► المعاينة في المتصفح (@remotion/player)
                  └─► التصدير MP4 على الخادم (@remotion/renderer)
```

- **المخرج المحلي**: يقسم القصة إلى جمل، ويتعرف على الأماكن (صحراء، قرية، مسجد، غرفة، باب، نافذة)، والشخصيات (البطل باسمه، شيخ، قرويون، أم، طفل، ظل)، والأفعال (يقود، تعطلت، مشى، جلس، نظر، التفت، فتح الباب، رن الهاتف، همس…)، والحوار بين «».
  يعمل جيدًا مع الجمل الواضحة؛ القصص المعقدة تحتاج مراجعة في المحرر أو مخرج Claude.
- **الشخصيات** (`src/remotion/Character.tsx`): هيكل SVG واحد (ثوب، شماغ/غترة، رأس، ذراعان، قدمان) بقوالب حركة: مشي، ركض، التفات، جلوس، نظر، كلام، خوف، فتح باب، هاتف، تجمد، طفو.
- **الأصول** (`Backgrounds.tsx`, `Props.tsx`): طريق صحراوي، قرية، مسجد صغير، غرفة مظلمة، باب قديم، منظر من النافذة، سماء ليل؛ سيارة، ساعة متجمدة، هاتف يرن، مصباح، مقعد، ظل في النافذة، عيون، دخان.
- **المؤثرات** (`scripts/make-sfx.py`): مركّبة بـ ffmpeg (رياح، همهمة، نبض، طرق، صرير، رنين، تعطل محرك، ضربة رعب، همس، خطوات، صراصير) — بلا ملفات خارجية أو حقوق.

## ملاحظات صريحة
- صوت espeak-ng مفهوم لكنه آلي وليس بلهجة سعودية. للصوت الطبيعي استخدم ElevenLabs أو ارفع تسجيلك.
- أذان الفجر لا يُولَّد صوتيًا؛ يظهر في النص والترجمة فقط.
- المخرج المحلي يفهم الفصحى والعامية السعودية الشائعة (شاف، طالع، طل، راح، شيبة، جوال، الشباك، خربت…). القصة المثال مكتوبة بالعامية.
- Remotion مجاني للأفراد والشركات الصغيرة؛ راجع رخصته إن كانت جهتك أكبر.
