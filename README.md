# الشمس تدق الجرس

رحلة تعليمية تفاعلية مع مواقيت الصلوات الخمس وفق المعتمد في مذهب الحنابلة، مع شرح صوتي ونص مكتوب في كل محطة.

- الموقع كله في `index.html`، بلا أدوات بناء.
- للنشر: اسحب المجلد إلى [Netlify Drop](https://app.netlify.com/drop) أو فعّل GitHub Pages على هذا المستودع.
- تفاصيل المشروع وقواعد المحتوى في `CLAUDE.md`.

---

## مشروع آخر في المستودع: منصة «الهمّة»

منصة مسابقات علمية تفاعلية عن أعلام التاريخ الإسلامي، في المجلد [`alhimma/`](alhimma/). تعمل بخادم Node.js، وتفاصيلها في [alhimma/README.md](alhimma/README.md).
