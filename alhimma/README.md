# الهمّة — منصة المسابقات العلمية والتفاعلية

> بالعلم نرتقي، وبالهمّة نسمو

منصة مسابقات عربية (RTL) للطلعة الأولى لمجموعة «الهمّة». تعرّف المشاركين بأعلام التاريخ الإسلامي: سيرهم وطبقاتهم ومؤلفاتهم ومواقفهم، وكل معلومة فيها مربوطة بمصدرها.

## التشغيل

يلزم Node.js 18 أو أحدث.

```bash
cd alhimma
npm install        # مرة واحدة (تحتاج إنترنت)
npm start          # ثم افتح http://localhost:3000
```

- **أول دخول إلى `/admin`:** تختار كلمة مرور المشرف، أو تضبطها مسبقًا بـ `HIMMA_ADMIN_PASSWORD=...`.
- **المنفذ:** `PORT=8080 npm start`. **مجلد البيانات:** `HIMMA_DATA=/path npm start`، والافتراضي هو `alhimma/data/`.
- **في الطلعة دون إنترنت:** شغّل المنصة على حاسوب، وشغّل نقطة اتصال (Hotspot) أو راوترًا، واربط الهواتف به. يطبع الخادم عند التشغيل عنوان الشبكة المحلية، ويظهر رمز QR للانضمام في شاشة الجلسة.
- **العرض على البروجيكتور:** زر ملء الشاشة أو المفتاح F. ويمكن فتح «شاشة العرض» المستقلة على جهاز والتحكم من جهاز آخر.

> هذه المنصة تحتاج خادمًا (Node)، فلا تعمل على Netlify Drop مثل موقع «الشمس تدق الجرس». للنشر على الإنترنت استعمل خدمة تشغّل Node، مثل Render أو Railway أو خادم خاص.

## الأقسام

| القسم | المسار |
|---|---|
| الصفحة الرئيسية: الفروع الأربعة، والفرع الجامع، وثماني ألعاب | `/` |
| اللعب الفردي | `/play?branch=hadith` · `/play?game=whoami` · `/play?grand=1` |
| المسابقة الجماعية (المشرف) | `/host` |
| انضمام المشاركين من الهواتف | `/join` |
| لوحة الإدارة | `/admin` |

**الفروع:** «فرسان الحديث»، «مجالس الفقه»، «ميادين العزيمة»، «مدارج الهمّة»، و«تحدي الهمّة الكبرى».
**الألعاب:** من أنا؟، الخط الزمني، شبكة العلماء، أمين المكتبة، الباحث الصغير، صحّح الترجمة، رحلة عبر القرون، الموسوعة المفقودة.
**أنواع التفاعل:** اختيار، كشف تدريجي، بطاقة تُكشف أجزاؤها بخصم، ترتيب بالسحب، ربط بين عمودين، توزيع على خانات، اكتشاف الخطأ، رفوف مكتبة، خريطة.

## المنهج العلمي في النظام

- كل معلومة عن علم «ادعاء» له إحالات (المصدر، الجزء، الصفحة، رابط الشاملة، المقتطف) وحالة: مسودة، أو قيد المراجعة، أو معتمد، أو مرفوض.
- **الألعاب لا تستعمل إلا المعتمد.** المحتوى المولّد آليًا يُحفظ مسودة دائمًا ولا يُنشر قبل اعتماد المشرف.
- إذا وردت روايتان مختلفتان في الوفاة أو الولادة أو المذهب، تظهر للمشرف في «المراجعة والتعارضات». الأسئلة لا تستعمل معلومة متعارضة.
- العلم يمكن أن ينتمي إلى أكثر من تصنيف، مع تصنيف رئيسي. التصنيف الزمني (القرن الهجري) يُحسب من سنة الوفاة المعتمدة.
- لا يُضاف علم من خارج القائمة المستوردة إلا بقرار المشرف.
- الربط بالمكتبة الشاملة: انظر [docs/SHAMELA.md](docs/SHAMELA.md). لا يوجد ربط مباشر، والمعتمد هو الاستيراد من الملفات وروابط الصفحات.

## البيانات التجريبية

تبدأ المنصة ببيانات تجريبية موسومة بـ«تجريبي» فيها 37 علمًا معروفًا ووقائع وأسئلة. وفيها مثالان على عرض الاختلاف: روايتان في سنة وفاة عاصم، وتاريخان لمعركة اليرموك.
**لا تحمل البيانات التجريبية أي إحالة أو رقم صفحة، ولا أقوالًا منسوبة.** يظهر للاعبين تنبيه بذلك.
تُحذف كلها بزر واحد: الإدارة ← الإعدادات ← حذف البيانات التجريبية.

## إدخال قائمتك ومصادرك

1. **الإدارة ← الاستيراد ← نص مصدر:** ارفع كتب التراجم المصدّرة من الشاملة (TXT/DOCX/HTML/PDF) واربط كل كتاب بمصدره، ومعه رقمه في الشاملة إن عرفته.
2. **الإدارة ← الاستيراد ← قائمة أسماء:** ارفع القائمة (TXT/DOCX/PDF/CSV/XLSX/JSON). تُنظف الأسماء وتوحد ويُزال المكرر، ثم تُطابق بالأعلام الموجودة وتُعرض مواضع ورود كل اسم في الكتب المستوردة. قرر لكل اسم: جديد، أو دمج، أو تجاهل.
3. افتح كل علم، وأضف معلوماته بإحالاتها، واعتمدها.
4. **الإدارة ← بنك الأسئلة ← توليد المسودات،** ثم راجع المسودات واعتمدها.
5. احذف البيانات التجريبية.

يمكن أيضًا استيراد ملف JSON منظم فيه الأعلام ومعلوماتها مع إحالاتها. يدخل كله «قيد المراجعة»، وصيغته موضحة في صفحة الاستيراد.

## البنية

```
server.js              نقطة التشغيل
server/app.js          الخادم والموجّه والواجهة البرمجية
server/db.js           قاعدة JSON بكتابة ذرية + نسخ احتياطي
server/auth.js         حماية الإدارة (scrypt + جلسة HttpOnly + حد المحاولات)
server/kb.js           القاعدة المعرفية: المعتمد، التعارضات، الإحالات، روابط الشاملة
server/generator.js    توليد مسودات الأسئلة من المعتمد
server/sessions.js     المسابقة الجماعية المباشرة (SSE) وحفظ الجلسات
server/importers.js    قراءة CSV/XLSX/DOCX/PDF/JSON/TXT/HTML
server/names.js        تنظيف الأسماء ومطابقتها والبحث في المصادر
server/demo.js         البيانات التجريبية
shared/                كود مشترك بين الخادم والمتصفح: العربية، الكتالوج، محرك الأسئلة
public/                الواجهات (بلا أدوات بناء)
```

**لإضافة فرع أو لعبة:** أضف تعريفها في `shared/catalog.js`. وإن احتاجت نمط أسئلة جديدًا، أضف مولّده في `server/generator.js` وطريقة عرضه في `public/js/qtypes.js`.
