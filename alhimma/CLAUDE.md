# الهمّة — منصة المسابقات العلمية (alhimma/)

مشروع مستقل داخل المستودع، لا علاقة له بموقع «الشمس تدق الجرس» في الجذر. خادم Node.js بلا أطر، وواجهات HTML/CSS/JS بلا أدوات بناء. التفاصيل في `README.md`، ودراسة الربط بالشاملة في `docs/SHAMELA.md`.

## قواعد علمية لا تُكسر
- لا تختلق شخصيات أو مصادر أو أرقام صفحات أو أقوالًا أو تعريفات. كل معلومة claim لها citations، والألعاب لا تستعمل إلا `status: approved`.
- المحتوى المولد آليًا (`/api/admin/generate`) يُحفظ `draft` دائمًا. لا تغيّر ذلك.
- البيانات التجريبية (`demo: true`) بلا إحالات، وتظهر بعلامة «تجريبي». لا تضف إليها أقوالًا منسوبة أو مصطلحات أو أرقام صفحات.
- عند استلام قائمة المستخدم: هي الأساس. لا تضف أعلامًا من خارجها إلا بإذن المشرف، ولا تعد بناء المشروع، بل استوردها عبر نظام الاستيراد.
- لا تدّع ربطًا مباشرًا بالشاملة: الموصّل `disabled` حتى يتوفر مفتاح رسمي.
- في التعارض بين المصادر: اعرض الروايات للمشرف، ولا تدمجها في جواب واحد.
- الكشف عن تعارض في الأحداث يكون بحقل `yearAlt`، والأحداث التي فيها `yearAlt` لا تدخل أسئلة الترتيب.

## سلوك يجب الحفاظ عليه
- RTL كامل، بلا تمرير أفقي على 390px، بلا نصوص عربية داخل SVG (العناوين فوق الخريطة عناصر HTML).
- الأصوات مولدة بـ WebAudio، والكتم محفوظ في `localStorage` (`himma-sound`)، والمفتاح M للكتم وF لملء الشاشة.
- اللعب الفردي: الأرقام 1-6 للاختيار، وEnter للتالي، وEsc للرجوع. المشرف: Enter للخطوة التالية، وP للإيقاف المؤقت.
- لا تضع شعار «Made with Claude» أو ما يشبهه.
- الطلبات المعدِّلة للواجهة البرمجية يجب أن تكون JSON، وملف تعريف الارتباط SameSite=Strict.

## الاختبار بعد أي تعديل
```
cd alhimma && npm test && node tests/e2e.js out
```
كل الفحوص يجب أن تكون PASS (26 + 80). اللقطات في `out/` (مستثنى من git).
